Devices trust the certificates issued here once this root certificate is installed on them. Check that the SHA-256 fingerprint the device shows matches the one above.

How to install it
Windows
Open the file, choose Install Certificate, then Place all certificates in the following store > Trusted Root Certification Authorities. Chrome and Edge use it after a restart.
macOS
Open the file to add it to Keychain Access, open the certificate there, expand Trust and set When using this certificate to Always Trust.
Linux
Debian/Ubuntu: sudo cp root_ca.crt /usr/local/share/ca-certificates/homelab-root.crt && sudo update-ca-certificates. Fedora: copy it to /etc/pki/ca-trust/source/anchors/ and run sudo update-ca-trust. Chrome and Firefox on Linux keep their own list: import it in the browser too.
Firefox
Settings > Privacy & Security > Certificates > View Certificates > Authorities > Import, and tick Trust this CA to identify websites.
iPhone, iPad
Download it in Safari, then Settings > Profile Downloaded > Install. Then Settings > General > About > Certificate Trust Settings and switch it on.
Android
Settings > Security > Encryption & credentials > Install a certificate > CA certificate. Only browsers use it; most apps ignore certificates you add.
